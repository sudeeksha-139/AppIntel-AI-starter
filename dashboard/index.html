Executive findings

The research covered 100 apps across 10 product categories. The automated collector successfully retrieved 91 app homepages in the November 24 run. It identified keyword signals for authentication (44 apps), API access (38 apps), API surface (33 apps) and MCP (30 apps). These are automated signals, not confirmed capabilities.

A manual review sample of 10 apps examined authentication, access requirements, API availability and MCP evidence. All 10 remain partially verified because the automated collection did not establish every finding independently. Official documentation was used to check the reviewed details.

Current status: 100 apps researched; 10 manually reviewed; accuracy percentage not yet established.

Research workflow

1 · Seed

Load the exact 100 apps and official starting URLs from the assignment.

2 · Discover

Fetch page metadata and flag API, OAuth, API-key, GraphQL and MCP references.

3 · Verify

Open official developer docs; record explicit auth, access requirements, API scope and MCP evidence.

4 · Synthesize

Cluster verified rows, calculate category patterns and publish only supported conclusions.
